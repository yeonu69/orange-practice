# 🍊 오렌지(Orange) 데이터 실습

중학교 1학년 영재교육용 오렌지 프로그램 실습 자료입니다. 모든 데이터는 연습용으로 **직접 만든 가상 데이터**입니다. (동물 수치는 대략값)

## 구성

| 파일 | 설명 |
|---|---|
| `data/1_아이스크림_기온.csv` | 여름 92일의 기온·강수량·요일·아이스크림 판매량 |
| `data/2_생활습관_수학점수.csv` | 학생 60명의 수면·게임·공부시간과 수학점수 |
| `data/3_신체데이터.csv` | 90명의 키·발크기·손길이·몸무게 |
| `data/4_동물_능력치.csv` | 동물 25종의 몸무게·속도·수명·수면시간 |
| `workflows/활동1~4.ows` | 활동별로 위젯이 미리 연결된 오렌지 워크플로 |
| `오렌지_실습_학생용_활동지.docx` | 인쇄용 학생 활동지 (아래한글에서 열기 가능) |
| `오렌지_실습_교사용_해설.docx` | 교사용 해설 (아래한글에서 열기 가능) |
| `학생용_활동지.md` | 단계별 실습 활동지 |
| `교사용_해설.md` | 정답 예시와 지도 팁 |

## 사용법

오렌지에서 **File** 위젯으로 CSV를 불러옵니다. 한글이 깨지면 인코딩을 UTF-8로 지정하세요.

## 워크플로(.ows) 사용법

1. `data/` 폴더와 `workflows/` 폴더를 같은 PC 폴더에 내려받습니다.
2. 오렌지에서 `.ows` 파일을 엽니다. (File 메뉴 → Open)
3. File 위젯을 더블클릭해 해당 활동의 CSV를 선택합니다.
4. Select Columns가 있는 활동은 Target(맞힐 것)과 Features(단서)를 정합니다.

워크플로는 위젯 연결만 담고 있어서, 열리지 않거나 연결이 어긋나면 활동지의 순서대로 직접 연결해도 됩니다.
